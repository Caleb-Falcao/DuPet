# 🔁 Rotas e Views

## Roteamento por app

### `users/urls.py`
- `/users/login/` → login_view
- `/users/signup/` → signup_view
- `/users/logout/` → logout_view

### `pets/urls.py`
- `/pets/` → listagem
- `/pets/novo/` → criação
- `/pets/<id>/editar/` → edição (em breve)

### `clinics/urls.py`
- `/clinics/` → listagem de clínicas (em desenvolvimento)
