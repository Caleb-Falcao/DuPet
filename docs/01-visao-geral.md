# 📘 Visão Geral do Projeto DuPet

DuPet é um sistema web desenvolvido em Django com o objetivo de facilitar o gerenciamento de pets e a busca por clínicas veterinárias.

## Objetivos principais
- Cadastro e gerenciamento de pets por usuários logados
- Visualização de pets cadastrados
- Busca de clínicas próximas (em desenvolvimento)
- Interface responsiva e amigável com Tailwind CSS

## Público-alvo
- Tutores de animais domésticos
- Clínicas veterinárias (em versões futuras)
